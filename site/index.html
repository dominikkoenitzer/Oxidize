Oxidize

Uninstall programs from your PC and clear out what they leave behind.

Download for Windows

For Windows 10 and 11.

If Windows says it protected your PC, click More info, then Run anyway.

Oxidize runs on Windows. Open this page on your Windows PC to download it.

What it does

  • Pick a program and click Remove completely. Oxidize runs the uninstaller that came with it, then removes what stayed behind: registry keys, folders, shortcuts, link types, services and scheduled tasks.
  • It takes a few seconds. At the end Oxidize looks again and tells you if anything is still there.
  • Everything it removes is backed up first, and Undo puts it back.
  • Windows' own folders and anything another installed program still uses are never touched.
  • To decide item by item, use Run uninstaller and Scan for leftovers instead: each leftover shows how sure Oxidize is, and you tick what goes.
  • Some leftovers can only go with administrator rights. Click Restart as admin at the top for those.

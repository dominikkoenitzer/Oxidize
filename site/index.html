Oxidize

Uninstall programs from your PC and clear out what they leave behind. One button removes a program completely, and Undo brings it all back.

Download for Windows

Windows 10 and 11, 64-bit. One file, nothing to install. The command line is oxidize.exe.

If Windows says it protected your PC, click More info, then Run anyway.

Oxidize runs on Windows. Open this page on your PC to download it.

Remove

One button, one question first

Remove completely closes the program's running copies, runs its own uninstaller when it needs one, removes everything found at high confidence and keeps a backup.

Nothing happens until you click Yes.

Result

It ends with Nothing left

After the removal Oxidize scans again. It says Nothing left, or lists what is still there and why, and counts the lower-confidence items it kept.

Leftovers

Finds what uninstallers leave behind

Oxidize looks through the registry, AppData, ProgramData, the Start menu, services, scheduled tasks, firewall rules and PATH.

High-confidence items start ticked; the medium ones wait for you.

Undo

Every removal can be undone

Before anything is deleted, registry keys are exported and files are moved into a backup folder. Undo puts every item back, and the log names each one.

Preview

See every item before it goes

With Dry run on, Remove completely changes nothing. It lists each item it would remove and each running process it would close.

Clean up

Clear out what Windows piles up

The Clean up tab measures temporary files, crash dumps, the Recycle Bin, browser caches, Windows' component store, the Delivery Optimization cache, an old Windows installation and folders of removed programs.

The safe ones start ticked. Recent files, a running browser and folders you protect stay, and caches never take cookies, history or logins with them.

Themes

Follows your Windows theme

Oxidize is light or dark, the way Windows is set.

AI assistant

Let your assistant clean up

oxidize mcp lets an AI assistant on your PC list programs, find leftovers and plan a removal. Nothing goes over the network.

A removal is always a plan first: what goes, with paths, sizes and reasons, and where the backup goes. Your assistant asks you before it carries a plan out, and every removed item is backed up.

The command line has --json on every command. Download the skill to teach your assistant all of it.

Requirements

What you need

  • Windows 10 or 11, 64-bit
  • About 9 MB to download
  • Administrator rights only for programs installed for all users
  • No install and no internet connection
Privacy

Nothing goes online

Oxidize has no network code. The assistant connection runs over your PC's own input and output, nothing else.

Your data

Only the backups

Each removal gets one backup folder under %LOCALAPPDATA%\Oxidize\backups, with the exported registry keys, the moved files and a list of every step. Oxidize keeps no other data.

Install, update and remove

01

Get started

  1. Download oxidize-gui.exe.
  2. Double-click it. There is nothing to install.
  3. Pick a program and click Remove completely.
02

Updates

Download the file again and replace the old one. Every release uses the same file names.

03

Removing it

Delete oxidize-gui.exe, and %LOCALAPPDATA%\Oxidize once you no longer need the backups in it.

Questions

Is Oxidize free?

Yes. It is free and open source under the MIT license.

Why does Windows say it protected my PC?

Oxidize is not signed with a paid certificate, so Windows warns about it the first time. Click More info, then Run anyway.

Can I undo a removal?

Yes. Everything is backed up before it is removed. Click Undo in the window, or use oxidize restore from the command line; oxidize backups lists them.

Does it remove things that belong to other programs?

Only high-confidence items go by default, each with the reason it matched. Windows' own folders are never touched, and a vendor folder that still holds another product stays.

Do I need the command line?

No. The window does everything. oxidize.exe is there for scripts, and a zip holds both.
